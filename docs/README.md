# doppeldata docs

Two kinds of page. A how-to page under `how-to/` runs one task: its commands first, CLI and Python
side by side, then its options, then output from a real run. A design page says why doppeldata is
shaped the way it is. It states its design as requirements the code must meet, and says what was
weighed and rejected.
